# ⛵ Vignette Voyages — Frontend Application

> **Vignette Voyages** is a modern React 18 single-page web application featuring a Sand & Warm Alabaster editorial aesthetic, responsive Bento Grid layouts, and interactive travel tools.

---

## 🌟 Application Features

- **Editorial Reading Experience**: Thoughtful typography, spacious visual layouts, and responsive media controls.
- **Destination Community Portals**: Explore worldwide travel destinations with community rankings, local highlights, and experience filters.
- **Interactive Budget Comparisons**: Live route spend benchmarks and anonymous expense submission controls.
- **Proof of Travel Validation**: Real-time EXIF image metadata parsing and verification badges.
- **Seamless Story Creation**: Intuitive publishing workflow with automated AI metadata suggestions.

---

## ⚡ Local Development Setup

### Prerequisites
- Node.js (v16+)
- npm (v8+)

### Installation
```bash
# Navigate to frontend directory
cd travel-blog-frontend

# Install dependencies
npm install

# Start development server
npm start
```

The application will run on **`http://localhost:3000`** and proxy API calls to the Node.js backend on **`http://localhost:5000`**.
